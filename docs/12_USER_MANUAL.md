# 1. Introduction

## 1.1 Overview

The **Room-Bot Service** is a hostel service management system designed to simplify communication between students and hostel staff. The application provides a centralized platform where students can request hostel-related services, submit complaints, track request progress, and provide feedback after services are completed. Hostel staff can efficiently manage assigned requests, update service statuses, and communicate with students through a structured workflow.

The system replaces traditional manual processes with a digital solution, improving service efficiency, transparency, and response time while reducing paperwork and communication delays.

---

# 1.2 Purpose of this User Manual

This User Manual serves as a comprehensive guide for all users of the Room-Bot Service. It explains how to access the application, navigate different features, perform common tasks, and resolve basic issues that may arise during normal usage.

The manual is intended to help users become familiar with the application without requiring any technical knowledge.

---

# 3. User Authentication

## 3.1 Overview

The Room-Bot Service uses a secure authentication system to ensure that only authorized users can access the application. Authentication protects user accounts and personal information while allowing users to access features based on their assigned role.

This section explains how to register, verify an account using email OTP, log in, recover a forgotten password, and log out securely.

---

# 3.2 Registration

New users must create an account before using the application.

### Student Registration

Follow these steps:

1. Open the Room-Bot Service.
2. Click **Register**.
3. Select **Student** as your user role.
4. Enter the required information:
   - Full Name
   - University Email Address
   - Hostel Block
   - Room Number
   - Password
   - Confirm Password
5. Click **Register**.
6. An OTP will be sent to your registered email address.
7. Enter the OTP.
8. After successful verification, your account will be activated.

---

### Staff Registration

Staff registration follows a similar process.

Required information:

- Full Name
- Institutional Email Address
- Assigned Hostel Block
- Password
- Confirm Password

After registration:

1. An OTP is sent to the registered email.
2. Enter the OTP.
3. Your account becomes active after successful verification.

---

# 3.3 Email OTP Verification

Email verification ensures that the registered email address belongs to the user.

Verification process:

```text
Registration
      │
      ▼
OTP Sent to Email
      │
      ▼
Enter OTP
      │
      ▼
OTP Verified
      │
      ▼
Account Activated
```

If the OTP expires:

- Request a new OTP.
- Check your spam or junk folder.
- Ensure that the correct email address was entered.

---

# 3.4 Logging In

After successful registration, users can log in to the application.

### Login Steps

1. Open the login page.
2. Select your user role.
3. Enter your registered email address (or administrator username).
4. Enter your password.
5. Click **Login**.

If the entered credentials are correct, the appropriate dashboard will open automatically.

---

# 3.5 User Roles During Login

Different users access different dashboards.

| User Role | Login Method | Dashboard |
|------------|--------------|-----------|
| Student | Email & Password | Student Dashboard |
| Staff | Email & Password | Staff Dashboard |
| Administrator | Username & Password | Admin Dashboard |

Each dashboard displays features relevant to that user role.

---

# 3.6 Forgot Password

If you forget your password, you can reset it securely.

Steps:

1. Click **Forgot Password**.
2. Enter your registered email address.
3. Click **Send OTP**.
4. Check your email.
5. Enter the received OTP.
6. Create a new password.
7. Confirm the new password.
8. Save the changes.
9. Log in using the new password.

---

# 3.7 Changing Your Password

Users can change their password after logging in.

General process:

1. Open **Profile**.
2. Select **Change Password**.
3. Enter your current password.
4. Enter a new password.
5. Confirm the new password.
6. Save the changes.

Use a strong password containing uppercase letters, lowercase letters, numbers, and special characters.

---

# 3.8 Logging Out

Logging out protects your account from unauthorized access.

To log out:

1. Click your profile icon or account menu.
2. Select **Logout**.
3. Wait until the login page appears.

Always log out when using a shared or public computer.

---

# 3.9 Common Authentication Issues

The table below lists common login and registration issues.

| Problem | Possible Solution |
|----------|-------------------|
| Incorrect Password | Verify the password or reset it using **Forgot Password**. |
| OTP Not Received | Check spam folder or request a new OTP. |
| Invalid OTP | Enter the latest OTP before it expires. |
| Email Already Registered | Log in using the existing account or reset the password. |
| Unable to Login | Verify your credentials and internet connection. |
| Session Expired | Log in again to continue using the application. |

Following these steps resolves most authentication-related issues.

---

# 3.10 Security Recommendations

For better account security:

- Never share your password with anyone.
- Use a strong and unique password.
- Do not share OTPs.
- Log out after every session on shared devices.
- Update your password regularly.
- Verify that you are using the official Room-Bot Service website.
- Keep your registered email account secure.

These practices help protect your account from unauthorized access.
